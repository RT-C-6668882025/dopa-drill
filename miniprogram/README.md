# Dopa Drill 微信小程序版

原生微信小程序迁移，不是 WebView 包装。

## 已完成
- 58 个 1–6 年级技能
- 完整 problems 生成器：横式、竖式、乘法、长除法、小数、分数、余数、比例、x
- 通用题面网格与逐格判题
- 技能前置解锁、熟练度、星级、Master
- 6/10/14 题训练、Combo、Score、Dopa 核心
- 微信本地存档、训练历史、连续登录
- 每日任务核心与任务页
- 47 项收藏/装扮目录与解锁展示
- 震动反馈、结果页、设置、数据清除

## 导入
微信开发者工具直接导入仓库根目录。project.config.json 已将 miniprogramRoot 指向 miniprogram/。当前 appid 为 touristappid，正式发布前替换为自己的小程序 AppID。

## 验收
从 1 年级开始训练，Master 前置技能后验证后续节点解锁；重点抽查 2 年级竖式、3 年级乘除与小数、4 年级长除法、5–6 年级分数/比例/x。退出重进后确认技能进度、历史、连续登录和设置仍存在。
